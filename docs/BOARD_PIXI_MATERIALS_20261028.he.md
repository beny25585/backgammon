# לוח וחומרי משחק ב־PixiJS — 28.10.2026

## אישור והיקף

המשתמש אישר את מראה האבנים לאחר צילום תצוגה עובדת וביקש: „אני רוצה גם את הלוח שתעשה עכשיו זה נראה טוב הצקרים”. בהמשך ביקש להסיר את פס „שש בש | 6B” משום שהוא תופס מקום. המימוש מחבר את האבנים והלוח לקוד המקומי הרגיל, ומשאיר את פעולות המשחק והנתונים ברכיבי React הקיימים. אין Git או פריסה.

## מבנה המימוש

- `GameFrame` מספק הקשר חומרים לערכת `charcoalGold`. ערכות שמורות אחרות ממשיכות עם משטחי התצוגה הקיימים.
- `PixiBoardSkin` מודד את המסגרת, 24 הנקודות, הפס המרכזי ושני תאי ההוצאה דרך `boardRect`, כולל סיבוב המסך הקיים במצב אנכי.
- `boardSkinRenderer` טוען נכסי חומר פרטיים ומפעיל מנוע Pixi יחיד. הוא מפיק פעם אחת שתי תמונות אבנים לשימוש חוזר, ומצייר מסגרת, עור, משולשים משובצים ומסילות לפי גבולות רכיבי המשחק בפועל.
- הלוח מצויר בטעינה ובשינוי גודל, בלי ticker רציף. הרזולוציה מוגבלת ל־2; המקורות והמשאבים מנוקים בסגירה.
- המספרים, מוני הפיפס, מוני ההוצאה, בחירה, יעדים חוקיים, גרירה ואנימציות נשארים רכיבי DOM. שכבת החומרים והאבנים הדקורטיביות אינן קולטות אירועי מצביע.
- העיצוב הקיים נשאר גלוי עד שהרינדור זמין. כשל טעינה או חוסר תמיכה בגרפיקה משאיר את משטחי התצוגה הקיימים.
- פס הכותרת הוסר. שורת הרשת שלו בגובה אפס, כך שאזורי המשחק בשורה השנייה מקבלים את השטח בלי לשנות את חוזה המיקום שלהם.

## נכסים ותלות

`pixi.js` בגרסה `8.22.0` נוסף לתלויות המקומיות, בטעינה דינמית של מודול החומרים. React לא שודרג.

- `src/assets/6b-checker-sprite-atlas.png`: אטלס האבנים מהמראה שנבחר; שתי אבנים, שנהב וגרפיט. נחתך וממוסך בזמן הרינדור, לא תמונת מסך של הלוח.
- `src/assets/6b-board-inlay-materials.png`: שני חומרי שיבוץ, זהב מאט ושנהב, שנוצרו ב־ImageGen המובנה.
- `src/assets/6b-charcoal-leather.png`: חומר העור הקיים ממוחזר למשטח ולמסגרת.

מקור הנכסים ופקודות הצילום: [תיקיית הראיות](../../artifacts/board-pixi-materials-20261028/README.md).

## פרטי API שנבדקו במימוש

ב־Pixi 8.22, עטיפת `FillPattern` מאפסת את גוון המילוי ללבן, ושינוי כתובת הדגימה לאחר יצירת texture דורש `style.update()`. לכן משטחי החומר משתמשים במילוי texture מפורש עם מטריצה גלובלית וגוון, ומעדכנים sampler לאחר הגדרת repeat. ההקשר הגרפי נבנה באצווה כדי שמשאבי גרדיאנט זמניים לא יישארו קשורים למטמון shader שאינו באצווה.

## אימות

TypeScript מלא ו־ESLint ממוקד עברו ללא שגיאות או אזהרות. [דוח האישור הסופי](../../artifacts/board-pixi-materials-20261028/final-capture-report.json) כולל את הנתיב המקומי הרגיל בארבע תצוגות: מחשב, טלפון אופקי, טלפון אנכי וערכת כחול שמורה. שלוש תצוגות הפחם מאמתות מנוע WebGL יחיד, שני חומרי אבנים, 24 נקודות ו־30 תמונות אבנים טעונות. בכחול נשמר הרינדור הקיים.

בארבעת הצילומים אין שגיאות או אזהרות, כל 24 המספרים בתוך שולי המסגרת, מוני הפיפס ב־18% ו־82% בתוך הפס, והשעונים בתוך עמודת השחקנים. שורת הכותרת בגובה אפס וללא תוכן. לאחר ההסרה שטח הלוח במחשב גדל בכ־49.55px ובטלפון בכ־28px; קוטר האבנים כ־64.625px במחשב ו־27px בטלפון. השינוי במידות מכוון ונובע מהשטח שהמשתמש ביקש להחזיר למשחק.

צילום האישור נשמר בקובצי `final-*`, בנפרד מצילום הבדיקה הראשון. הצילום ממתין לטיק האמיתי הראשון של השעון המקומי כדי לא לצלם ערך השהיה חולף לפני עדכון התצוגה הראשון; קוד השעון לא שונה. אין החלפת רכיבים בצילום הסופי, ספק מצב מדומה או נתוני חשבון מומצאים. נתוני הקוביות המקומיים מיוצבים לצילום. tests ו־build, מכשיר פיזי, משחק מקוון ופריסה לא הורצו.

פקודות למשתמש, מתוך `Backgammon Game/frontend`, אחת בכל פעם:

```powershell
pnpm test src/components/GameScreen/GameScreen.test.tsx src/components/GameScreen/GameScreen.responsive.test.tsx src/components/GameScreen/GameBoard.test.tsx src/components/Board/Board.responsive.test.tsx src/components/Board/Board.drag.test.tsx src/components/Board/Board.numbering.test.tsx
pnpm build
```

## המשך לפי המספור — סעיפים 3 ו־4

28.10.2026 — המשתמש בחר „תמשיך עכשיו עם 3 ו4” והבהיר שעובדים לפי המספרים מהרשימה שנמסרה:

- **3 — המשולשים ומספרי הנקודות:** מרקם שיבוץ עדין יותר, שנהב ופליז בגימור מאט, תאורה עקבית בשתי שורות הלוח ותפר מגע צר. המספרים שומרים על הגודל והמיקום הקיימים ומקבלים הבלטה זהובה חדה ועדינה.
- **4 — הפס המרכזי ומוני הפיפס:** פני פס חלקים ועדינים יותר עם שיפוע ושוליים כהים; חלוניות כהות ושקועות עם שפה חמימה דקה. רוחב החלוניות, ריווח של 14% בצדדים ומרכזים של 18% ו־82% נשמרים.

השינוי מוגבל לקטעי המשולשים והפס ברינדור, למראה מספרי הנקודות ולחלוניות הפיפס. המסגרת, האבנים, המסילות, הקוביות והפעולות אינן חלק מהסבב. אין נכסים או תלויות חדשים. במהלך אימות הדפדפן תוקנה גם בעלות נתון האבחון `__boardPixiProof`: רק הרינדור המוצג מפרסם את הנתון, כדי שיצירה אסינכרונית שבוטלה לא תחליף אותו בנתון של מנוע שכבר נסגר. תיקון זה אינו משנה את מצב המשחק.

TypeScript מלא ו־ESLint לשלושת קובצי המקור עברו ללא שגיאות או אזהרות. [דוח האישור של סעיפים 3–4](../../artifacts/board-items-3-4-20261028/final-capture-report.json) מאמת ארבע תצוגות דפדפן ללא שגיאות או אזהרות, עם הפרש אפס במידות ובמיקומים של המסגרת, השדה, הפס, הנקודות והאבנים לעומת התוצאה שאושרה. שלוש תצוגות הפחם כוללות 30 אבנים טעונות; ערכת כחול שומרת את התצוגה הקיימת. ערכי הפיפס תואמים למיקום האבנים, 167 לכל צד בדוגמת הפתיחה, ומרכזיהם ב־18% וב־82%. טווחי הספרות בפחם מרוחקים לפחות 3.14px משולי המסגרת במחשב ו־1.5px בטלפון. בכחול טווח הגופן כולל leading חיצוני קיים, אך תקריב הצילום מאמת שהספרות עצמן אינן נחתכות.

השוואת SHA-256 מאמתת שקובצי הצ׳קרים, מסגרת המשחק ומסילות ההוצאה נשארו ללא שינוי. [ראיות ותקריבים](../../artifacts/board-items-3-4-20261028/README.md) נשמרים בנפרד מהסבבים הקודמים. tests/build ומכשיר פיזי נשארים לאימות המשתמש; לא בוצעו Git או פריסה.
