# Backgammon Game Development Agent

Full-stack Backgammon game with online multiplayer (WebSocket) and local AI opponent.

## Tech Stack

- **Frontend**: React 19 + TypeScript + Vite + Tailwind CSS 4 + Motion
- **Backend**: Django 5 + Channels 4 + Daphne + SimpleJWT + SQLite
- **Engine**: Pure TypeScript + Python (same rules, independent implementations)

## Key Architecture

### Routing (`src/router.tsx`)
- `/` → AuthScreen, `/home` → HomeScreen, `/waiting/:roomId` → WaitingRoom
- `/game/:roomId?color=` → GameProvider + GameScreen
- `/local` → LocalGameProvider (human vs human)
- `/local?bot=black&target=7` → LocalGameProvider vs AI with match target
- Auth guards: `RequireAuth`, `RedirectIfAuthed`

### State Providers
- **`GameProvider`** (`gameContext.tsx`) — WebSocket multiplayer
- **`LocalGameProvider`** (`localGameContext.tsx`) — local + AI + match scoring

### Engine (`lib/backgammon/engine.ts`)
- Pure functions only — no side effects, no mutations
- Exports: `BAR`, `OFF` constants, `Source`/`Target` types
- Functions: `newGame`, `applyMove`, `allLegalMoves`, `applyRoll`, `applyOpeningRoll`, `offerDouble`, `respondDouble`

### Bot AI (`lib/bot/`)
- Adapted from [backgammon-baddie](https://github.com/devensimonson/backgammon-baddie) (MIT)
- `evaluate.ts`: pip count, blot exposure, made points, home board, primes
- `chooseMove.ts`: 1-ply search, deterministic (first best on tie)

## Component Patterns

- One folder per component: `ComponentName/ComponentName.tsx` + `.module.css` + `index.ts`
- `useGame()` hook for state access (never prop drill game state)
- CSS Modules for scoped styles, Tailwind for layout/utilities

## Key Conventions

- `BAR` / `OFF` constants instead of `"bar"` / `"off"` string literals
- `Source` = `number | "bar"`, `Target` = `number | "off"`
- Match target via URL param: `?target=N` (default 7)
- Bot color via URL param: `?bot=black` or `?bot=white`
- Game result overlay auto-advances after 30s for multi-game matches

## Common Tasks

### Adding a component
1. Create `components/Name/Name.tsx` + `Name.module.css` + `index.ts`
2. If it needs game state, import `useGame()` from `services/gameContext`
3. Export default from `index.ts`

### Adding a route
1. Add `<Route>` in `src/router.tsx`
2. Wrap in `RequireAuth` if login needed
3. Add navigation call via `useNavigate()` in the source component

### Debugging local mode
- Game state in `LocalGameProvider` uses `useReducer`-style `setState`
- Bot actions in `useEffect` with `BOT_DELAY = 400ms`
- Match scoring in separate `useEffect` watching `state.phase === "game_over"`

## Production Deployment

### Frontend Config
- `base: '/backgammon/'` in `vite.config.ts`
- `VITE_SERVER_URL=/backgammon` in `.env`
- `BrowserRouter basename="/backgammon"` in `main.tsx`

### Backend Config
- `settings.py` uses `python-decouple` for all secrets
- PostgreSQL via `dj-database-url`, Redis via `channels_redis`
- Logging → `/var/log/backgammon/django.log`

### Nginx (served under `/backgammon/`)
- `/backgammon/api/` → `proxy_pass http://127.0.0.1:8005/api/`
- `/backgammon/ws/` → `proxy_pass http://127.0.0.1:8005/ws/` (with Upgrade headers)
- `/backgammon/` → serve `frontend/dist/` (SPA fallback)
- `/backgammon/static/` → serve `backend/staticfiles/`

### Daphne Systemd Service
- Port 8005, `DJANGO_SETTINGS_MODULE` env var required
- Import order in `asgi.py`: `get_asgi_application()` before channels/routing imports

### Monitoring (Alloy → Loki → Grafana)
- Alloy tails `/var/log/backgammon/*.log` + systemd journal for `backgammon.service`
- Grafana query: `{job="backgammon"}`
