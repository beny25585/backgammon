# Game development context

Updated 2026-09-19 from the local working tree. This file describes the project; it is not a deployment record.

- React 18.2 / TypeScript / Vite 8 frontend; Tailwind 4 plus CSS Modules and Motion.
- Django 4.2.7 / Channels / Daphne game server; internal Elixir dice service.
- / and /home redirect to the separate Vue club. /link establishes game authorization, /game/:roomId uses GameProvider, /local uses LocalGameProvider, and history routes require authorization.
- Server gameplay is authoritative. Send intents using the existing WebSocket contract. Client state must not determine linked results, payouts or Elo.
- Local TypeScript bot and server Open Sage are separate. The club UI loads practice pricing/options and uses the prepare/charge/enter server contract; consult the practice document before modifying integration.
- Persisted tasks require recurring run_tasks execution. Redis is the default channel layer; memory is for a single local process.
- Assistant is the current global body and display font. Use existing tokens, board themes and CSS Modules. Club/admin styles are separate.
- Keep service credentials in server configuration. VITE variables are public client configuration.
